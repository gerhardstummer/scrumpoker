FUNKTIONALE ANFORDERUNGEN

ALLGEMEIN:
- Keine Datenbank, alles über PHP-Sessions.
- Login mit Name, Raumname und Rolle (User, Moderator, Admin) so wie Auswahl der Sprache.
- Admins sehen Adminbereich
- Admins + Moderatoren dürfen Runde zurücksetzen und Karten für alle sichtbar aufdecken.
- Admins + MOderatoren können für alle im selben Raum die Sichtbarkeit der Kartensets global bestimmen (Fibonacci oder T-Shirt, oder auch Beide).
- Admin ist auch Moderator
- Moderator ist auch User
- Admin, Moderator und User in einem Raum sehen sich in der Teilnehmer-Liste

- Votes werden automatisch zurückgesetzt, wenn das Set geändert wird.
- Live-Status-Updates über AJAX (Polling).
- Dark-Mode per Button für alle ermöglich.
- Default soll ein Light Mode gewählt sein.
- der Countdown-Block ist unsichtbar.
- wenn der Moderator aufdecken wählt, wird Countdown-Block für alle eingeblendet und der Countdown startet.
- wenn der Countdown 0 erreicht wird der Countdown-Block wieder ausgeblendet und alle Karten der Teilnehmer im Raum aufgedeckt. 
- wenn der Countdown 0 erreicht hat können keine Karten mehr geklickt werden, bis der Moderator zurückgesetzt hat.

- in der Teilnehmerliste sind alle User im Raum mit ihrem Namen und der ROlle in Klammer gelistet.
- es gibt auch ein eigenes Symbol vor dem Namen für jede Rolle.
- wenn ein User eine Karte gewählt hat, so ist das in der Teilnehmer-Liste durch ein Kartensymbol für alle sichtbar. Die Karte bleibt vorerst noch verdeckt,
- die gewählte Karte eines Teilnahmers wird aber erst für alle im Raum aufgedeckt, wenn der Moderator aufdecken wählt und der Countdown abgelaufen ist.
- Teilnehmerliste sortiert nach Rolle (Admin, Moderator, User)
- Alle Teilnehmer im selben Raum sollen sich in der Teilnehmerliste sehen und auch darüber synchronisiert sein.
- Zeige die Werte der Loginmaske auch in der URL als URL-Parameter (user,room,role,lang) an und umgekehrt. Wenn die URL Parameter vollständig sind (lang kann fehlen, das es default auch deutsch ist), dann wird die Login-Maske übersprungen.

STATISTIK:
- Fibonacci: Anzahl, Mittelwert, Median, häufigste Karte(n). 
- T-Shirt: Anzahl, 
           häufigste Karte(n): sollten hier mehrere Karten die selbe höchste Häufigkeit haben, dann sollen diese alle mit Komma separiert gelistet werden 
- Empfehlung:
        Wenn Median einem Kartenwert entspricht -> Median
        Sonst eindeutige häufigste Karte
		
- getrennte Statistik für nummerische Decks (Fibonacci, Personentage) und Nicht-Nummerische (T-Shirt).
- Statistik darf NIE abbrechen, auch bei gemischten Votes.
- T-Shirt Size ist dabei eine nicht nummerische Größe, prinzipiell soll die Statisitik auch für nicht nummerische Werte möglich sein
- wenn mehrere verschiedene Karten die selbe häufigkeit haben, dann sollen alle Karten mit der selben höchsten Häufigkeit gelistet werden.
- Die Statistik wird erst angezeigt und aktualisiert, wenn die Karten aufgedeck werden.
- Die Statistik wird zurückgesetzt wenn Moderator auf Zurücksetzen klickt.

LAYOUT
---------------------------------------

Die Applikation besteh aus einer Login-Maske und der Hauptmaske
Die Login Maske beistzt Eingabe Felder mit Benutzer, Raumname, User-Rolle, einer Combobox für die Auswahl der Sprache. Die Sprache ist per Default vorbelegt mit "Deutsch" und einen Login-Button, der beim Klick auf die Hauptmaske wechselt, wenn alle Felder korrekt befüllt sind.
Die Login-Daten der Maske werden als URL-Parameter übernommen und angezeigt, könnten dort auch jederzeit dynamisch abgeändert werden. Wenn Sprache als URL-Parameter fehlt, dann wird "Deutsch" als default übergeben.
Wenn die Felder der Login-Maske ausgefüllt werden, wird autoamtisch der Parameter auch sofort in die URL übernommen.
Wenn die URL Parameter Benutzer, Raumname, User-Rolle enthalten, dann wird die Loginmaske übersprungen und man kommt gleich zur Hauptmaske

Die Hauptmaske sieht so aus:

ganz oben in der Titelleiste links soll "Scrumpoker für den Raum" dann der Raumname in Klammern folgen. 
Rechtlinks ist der angeneldete User mit seiner Rolle sichtbar, ein Toggle für Wahl des Dark- und Light-Modus soll angezeigt werden, ganz rechts existiert ein Abmelde-Link der bei Klick wieder zur Login-Maske führt

LINKER BEREICH (von oben nach unten):
1. Moderations-Panel (Karten aufdecken, Zurücksetzen) nur für Moderatoren sichtbar
2. Karten-Panel
3. Story-Panel: im Story-Panel sollen die Kartenset getrennt untereinander dargestellt werden

RECHTER BEREICH (von oben nach unten):
1  Countdown-Panel für alle Rollen sichtbar
2. Teilnehmer-Panel für alle Rollen sichtbar
3. Statistik-Panel für alle Rollen sichtbar
4. Deck-Konfiguration (nur Rolle Admin sichtbar)
5. Raumliste (nur Rolle Admin sichtbar)

Countdown:
Der Countdown wird erst eingeblendet wenn Moderator auf aufdecken klickt.

Wenn der Countdown abgelaufen ist, wird er wieder für alle ausgeblendet.
Ergänze den Countdown um einen dynamischen SVG-Fortschrittskreis (Circular Progress Bar)

Style:
Im Style soll keine Farbe grün verwendet werden.
Der Light Mode soll graue und blaue Farbtöne enthalten.
Die Bezeichnungen Labels und Buttons sollen default auf deutsch erfolgen,
Ganz oben rechts soll aber eine Combobox mit den Sprachen deutch, englich, ungarisch erscheinen. Je nach gewählter Sprache können die Texte zur Laufzeit entsprechend angezeigt werden.
Per Default soll die Sprache "deutsch" gewählt sein.
Die Karten sollen als Spielkarten klar erkennbar sein, verwende dafür einen modernernen Spielkarten-Style, an den Kartenrändern soll auch der Wert etwas kleiner, wie bei Spielkarten üblich zu sehen sein.
Bei einem Hover der Karte springen sie leicht auf
Der Hintergrund von nicht gewählten Karten soll grau verlaufend sein
Wenn eine Karte durch einen Klick gewählt wird, dann soll diese einen deutlich markierten Glow besitzen und etwas größer dargestellt sein, als nicht gewählte Karten.
Wenn eine Karte aufgeklappt wird oder durch erneuten Klick wieder abgewählt wird, soll ein animierter Dreheffekt der Karte zu sehen sein.
Der Countdown soll mindestens genau so groß sein, wie eine Karte. Es soll Clean Circular Countdown mit Segementen sein, Farbe in Blau
- style die Karten im Neumorphism Style
- Erzeuge ein UI im Neumorphic Design

Eingabefelder:

die Kartensets sollen ebefalls editierbar sein.
die Story im Story-Panel wird mit jedem Reset wieder zurückgesetzt.
Die Werte der Kartensets sollen pro Raum gespeichert werden und sind vom Admin veränderbar.
